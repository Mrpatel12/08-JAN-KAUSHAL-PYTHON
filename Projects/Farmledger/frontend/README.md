# FarmLedger Frontend

Scaffolded Vite + React + TypeScript frontend with Tailwind CSS and React Query.

Quick start:

```bash
cd frontend
npm install
npm run dev
```

Dev server runs on `http://localhost:3000` by default.

Design system:
 - CSS tokens: `src/styles/tokens.css` (light/dark variables)
 - UI primitives: `src/components/ui` (Button, Input, Card, Modal)
